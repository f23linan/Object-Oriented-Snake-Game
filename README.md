# Java Snake Game

## Description
A classic Snake game developed in Java, featuring two difficulty modes: Normal and Expert. The objective is to reach 25 points while avoiding collisions with walls and the snake's own body.

## Game Features
- **Normal Mode:** Only food spawns.
- **Expert Mode:** Both food and poison spawn, adding an extra challenge.
- Eating food increases the snake's length and score.
- Eating poison decreases the snake's length and score.
- New food or poison spawns whenever an item is consumed.
- The game can be restarted after winning or losing, with the option to select a difficulty again.
- The snake starts in the centre of the gameboard and moves automatically.

## Technologies
- Java
- Object-Oriented Programming

## Objective
Reach 25 points to win. Colliding with a wall or the snake's own body results in a game over.
